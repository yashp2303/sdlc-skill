name: sdlc-skills
description: A bundle of five Claude Code skills that carry a ticket through the whole SDLC — /ticket-research (read-only research.md, 25 sections, every name checked for existence), /feature-docs (the five-file docs pack: spec.md · plan.md · test-cases.md · test-cases.csv · qa-sheet.md), /tsc-ticket (implement, verify, report, with ticket-local test files that run but never reach git), /testing (execute unit → integration → API → Playwright UI → regression, then test-report.md and a marked CSV), and /rca (read-only bug investigation to the first incorrect state). Everything lands in one folder per ticket, docs/<TICKET-ID>-<slug>/. Use when a ticket, feature requirement, change request, or production bug arrives and you need it researched, specified, planned, implemented, tested, or root-caused. Every claim carries a file:line; nothing is called passing unless it was executed and observed.
